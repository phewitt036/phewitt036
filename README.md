## What I'm Building

### [Pixit](https://github.com/phewitt036/Pixit) — [usepixit.com](https://usepixit.com)
A web app that extracts structured data from gig platform screenshots and pushes records to Salesforce or Google Sheets. Built with Node.js, Claude Haiku (vision), SQLite, and deployed via Cloudflare Tunnel on a Raspberry Pi 5. Exploring as a multi-vertical SaaS product for gig workers and freelancers.

### [Salesforce Gig Income Tracker](https://github.com/phewitt036/salesforce-gig-income-tracker)
A custom Salesforce developer org that tracks Uber and DoorDash income at the trip level. Custom data model, Lightning Web Component for quick entry, dashboards, and automated record creation via Pixit.

### [Fourth and Oklahoma](https://github.com/phewitt036/fourth-and-oklahoma)
A multi-agent AI system that writes and delivers a daily Oklahoma sports newsletter. Three OpenClaw agents — Scout (data gathering), Pam (writing + delivery), and Claw (general assistant) — run on a Raspberry Pi 5 with a custom Flask sports data API aggregating the NBA, MLB, NFL, and college football feeds.
