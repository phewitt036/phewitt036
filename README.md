## What I'm Building

### [Pixit](https://github.com/phewitt036/Pixit) — [usepixit.com](https://usepixit.com)

Built with Node.js and SQLite, self-hosted on my own Linux server behind Cloudflare Tunnel. I use it every day to log my own gig income.

### [Salesforce Gig Income Tracker](https://github.com/phewitt036/salesforce-gig-income-tracker)
The Salesforce org I ran my gig-driving business on for two years. Custom data model, Lightning Web Component for quick entry, dashboards, and automated record creation via Pixit.

### Salesforce → PostgreSQL migration
When the business outgrew a Developer Edition org, I migrated all 1,749 records into a custom PostgreSQL data model, with a record-level reconciliation that found 15 data defects in the source org.

### [Fourth and Oklahoma](https://github.com/phewitt036/fourth-and-oklahoma)
A multi-agent AI system that writes and delivers a daily Oklahoma sports newsletter. Three OpenClaw agents — Scout (data gathering), Pam (writing + delivery), and Claw (general assistant) — with a custom Flask sports data API aggregating the NBA, MLB, NFL, and college football feeds.
